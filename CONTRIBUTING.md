# Contributing to Pengu AI

First off, thank you for considering contributing to Pengu AI! It's people like you who make Pengu AI such a powerful automated solution.

To keep our contribution graph healthy and our codebase clean, please follow these guidelines.

## 🚀 Our Workflow

We follow an **Issue-First** and **Branch-Based** workflow.

1.  **Find or Create an Issue**: Before starting any work, ensure there is an issue describing the task.
2.  **Create a Branch**: Create a new branch from `main`.
    *   `feature/your-feature-name`
    *   `bugfix/issue-description`
    *   `docs/update-readme`
3.  **Commit Often**: Make small, descriptive commits.
4.  **Open a Pull Request**: When ready, open a PR against the `main` branch.
5.  **Code Review**: At least one review (even a self-review with comments) is required before merging.

## 📝 Commit Message Guidelines

Use clear and descriptive commit messages:
*   `feat: add dark mode toggle`
*   `fix: resolve memory leak in testimonial slider`
*   `docs: update installation steps in README`

## 🛠 Development Setup

1.  Clone the repo: `git clone https://github.com/royestheking-a11y/Pengu-AI.git`
2.  Install dependencies: `npm install`
3.  Set up your `.env` (see `.env.example`).
4.  Start dev server: `npm run dev`

## 🤝 Code of Conduct

Help us keep Pengu AI a professional and welcoming project. Be respectful, constructive, and helpful to other contributors.
